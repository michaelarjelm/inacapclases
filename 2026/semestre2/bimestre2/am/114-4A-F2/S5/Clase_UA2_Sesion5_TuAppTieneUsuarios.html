●
Por qué no lo guardamos en el teléfono

Si la cuenta quedara solo en tu teléfono, no podrías ingresar desde otro, y cualquiera con acceso al teléfono podría leer las claves. Las cuentas se guardan en un servidor que las protege.

Definición
El servicio que usamos desde hoy
Qué es
Firebase
Firebase
Un conjunto de servicios de Google para apps: guarda usuarios, datos y archivos en internet, y tu app los usa con unas pocas líneas de código, sin que tú programes un servidor.
Ejemplo: Mi Música guarda sus cuentas en Firebase Authentication. En la clase asincrónica 2 va a guardar las canciones en Firestore, otro servicio de Firebase.
Firebase Authentication
El servicio de Firebase que crea cuentas, revisa el correo y la clave al ingresar, y recuerda quién tiene la sesión abierta.
Ejemplo: cuando alguien toca Crear cuenta en Mi Música, Authentication guarda ana@prueba.cl con su clave protegida. Tú nunca ves la clave.
●
Es gratis

Usamos el Plan Spark, el gratuito. No pide tarjeta. Si en algún momento la consola te ofrece Actualizar o Plan Blaze, no lo aceptes: no lo necesitas en este curso.

Definición
Lo justo para entender los tres archivos que siguen
Cómo se suma
una librería
Gradle
Función: La herramienta que arma tu app: junta tu código con las librerías que usa y produce el APK que se instala.
Ejemplo: Cuando tocas Run, Gradle compila Mi Música con AppCompat, RecyclerView y, desde hoy, Firebase.
libs.versions.toml
Función: La lista de librerías y versiones del proyecto. Se escribe el nombre y la versión una vez y los build.gradle.kts la usan por su apodo.
Ejemplo: firebaseBom = "34.12.0" en [versions], y firebase-auth en [libraries].
Plugin google-services
Función: Una extensión de Gradle que lee google-services.json y deja esos datos dentro de la app.
Ejemplo: Sin el plugin, la app no sabe a qué proyecto de Firebase conectarse.
BoM (lista de materiales)
Función: Un número de versión que elige por ti las versiones de todas las librerías de Firebase, para que funcionen entre ellas.
Ejemplo: Con firebase-bom 34.12.0, firebase-auth no lleva versión propia: la toma de la BoM.

class RegistroActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContentView(R.layout.activity_registro)
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main)) { v, insets ->
            val systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars())
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom)
            insets
        }

    fun btnCrearCuentaOnClick(view: View) {
        val edtNombre = findViewById<EditText>(R.id.edtNombre)
        val edtCorreo = findViewById<EditText>(R.id.edtCorreo)
        val edtClave = findViewById<EditText>(R.id.edtClave)
        val edtRepetirClave = findViewById<EditText>(R.id.edtRepetirClave)
        val rgGenero = findViewById<RadioGroup>(R.id.rgGenero)
        val chkTerminos = findViewById<CheckBox>(R.id.chkTerminos)

        val nombre = edtNombre.text.toString().trim()
        val correo = edtCorreo.text.toString().trim()
        val clave = edtClave.text.toString()
        val repetirClave = edtRepetirClave.text.toString()

        if (nombre.isEmpty()) {
            edtNombre.error = "Escribe tu nombre"
            edtNombre.requestFocus()
            return
        }
        if (!Patterns.EMAIL_ADDRESS.matcher(correo).matches()) {
            edtCorreo.error = "El correo no es válido"
            edtCorreo.requestFocus()
            return
        }
        if (clave.length < 6) {
            edtClave.error = "Mínimo 6 caracteres"
            edtClave.requestFocus()
            return
        }
        if (clave != repetirClave) {
            edtRepetirClave.error = "Las contraseñas no coinciden"
            edtRepetirClave.requestFocus()
            return
        }
        if (!chkTerminos.isChecked) {
            Toast.makeText(this, "Debes aceptar los términos", Toast.LENGTH_SHORT).show()
            return
        }

        val rbElegido = findViewById<RadioButton>(rgGenero.checkedRadioButtonId)
        val genero = rbElegido.text.toString()

        val auth = FirebaseAuth.getInstance()
        auth.createUserWithEmailAndPassword(correo, clave)
            .addOnCompleteListener(this) { tarea ->
                if (tarea.isSuccessful) {
                    Toast.makeText(this, "Cuenta creada, $nombre. Te gusta: $genero", Toast.LENGTH_LONG).show()
                    auth.signOut()
                    finish()
                } else if (tarea.exception is FirebaseAuthUserCollisionException) {
                    edtCorreo.error = "Este correo ya tiene una cuenta"
                    edtCorreo.requestFocus()
                } else {
                    Toast.makeText(this, "No se pudo crear la cuenta: ${tarea.exception?.message}", Toast.LENGTH_LONG).show()
                }
            }
    }

    fun txtIrLoginOnClick(view: View) {
        finish()
    }
}

            val intent = Intent(this, ListaActivity::class.java)
            startActivity(intent)
            finish()
        }
    }

    fun btnIngresarOnClick(view: View) {
        val edtCorreo = findViewById<EditText>(R.id.edtCorreo)
        val edtClave = findViewById<EditText>(R.id.edtClave)
        val correo = edtCorreo.text.toString().trim()
        val clave = edtClave.text.toString()

        if (correo.isEmpty()) {
            edtCorreo.error = "Escribe tu correo"
            edtCorreo.requestFocus()
            return
        }
        if (!Patterns.EMAIL_ADDRESS.matcher(correo).matches()) {
            edtCorreo.error = "El correo no es válido"
            edtCorreo.requestFocus()
            return
        }
        if (clave.length < 6) {
            edtClave.error = "Mínimo 6 caracteres"
            edtClave.requestFocus()
            return
        }

        val auth = FirebaseAuth.getInstance()
        auth.signInWithEmailAndPassword(correo, clave)
            .addOnCompleteListener(this) { tarea ->
                if (tarea.isSuccessful) {
                    Toast.makeText(this, "Hola, $correo", Toast.LENGTH_SHORT).show()
                    val intent = Intent(this, ListaActivity::class.java)
                    startActivity(intent)
                    finish()
                } else {
                    Toast.makeText(this, "Correo o contraseña incorrectos", Toast.LENGTH_LONG).show()
                }
            }
    }

    fun txtRegistroOnClick(view: View) {
        val intent = Intent(this, RegistroActivity::class.java)
        startActivity(intent)
    }
