Tres piezas para moverse entre pantallas
Abrir y
volver
Intent
Función: el pedido para abrir otra pantalla: desde dónde y hacia cuál.
Ejemplo: Intent(this, ListaActivity::class.java): desde el login, abrir la Lista.
startActivity
Función: envía el pedido. La pantalla nueva queda encima de la actual.
Ejemplo: Ingresar abre la Lista encima del Login.
finish()
Función: cierra la pantalla actual. Se ve la que estaba debajo, sin crear nada nuevo.
Ejemplo: la X de la IA cierra la IA y aparece la Lista que estaba debajo.
●
Por qué volver no es abrir

Si la X de la IA hiciera Intent hacia la Lista, quedarían dos Listas apiladas, y el botón atrás del teléfono mostraría la repetida.

fun btnIngresarOnClick(view: View) {
    val edtCorreo = findViewById<EditText>(R.id.edtCorreo)
    val edtClave = findViewById<EditText>(R.id.edtClave)
    val correo = edtCorreo.text.toString().trim()
    val clave = edtClave.text.toString()

    if (correo.isEmpty()) {
        edtCorreo.error = "Escribe tu correo"
        edtCorreo.requestFocus()
        return
    }
    if (!Patterns.EMAIL_ADDRESS.matcher(correo).matches()) {
        edtCorreo.error = "El correo no es válido"
        edtCorreo.requestFocus()
        return
    }
    if (clave.length < 6) {
        edtClave.error = "Mínimo 6 caracteres"
        edtClave.requestFocus()
        return
    }

    Toast.makeText(this, "Hola, $correo", Toast.LENGTH_SHORT).show()
    val intent = Intent(this, ListaActivity::class.java)
    startActivity(intent)
}

package com.example.mimusica

import android.content.Intent
import android.os.Bundle
import android.util.Patterns
import android.view.View
import android.widget.EditText
import android.widget.Toast
import androidx.activity.enableEdgeToEdge
import androidx.appcompat.app.AppCompatActivity
import androidx.core.view.ViewCompat
import androidx.core.view.WindowInsetsCompat

class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContentView(R.layout.activity_main)
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main)) { v, insets ->
            val systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars())
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom)
            insets
        }
    }

    fun btnIngresarOnClick(view: View) {
        val edtCorreo = findViewById<EditText>(R.id.edtCorreo)
        val edtClave = findViewById<EditText>(R.id.edtClave)
        val correo = edtCorreo.text.toString().trim()
        val clave = edtClave.text.toString()

        if (correo.isEmpty()) {
            edtCorreo.error = "Escribe tu correo"
            edtCorreo.requestFocus()
            return
        }
        if (!Patterns.EMAIL_ADDRESS.matcher(correo).matches()) {
            edtCorreo.error = "El correo no es válido"
            edtCorreo.requestFocus()
            return
        }
        if (clave.length < 6) {
            edtClave.error = "Mínimo 6 caracteres"
            edtClave.requestFocus()
            return
        }

        Toast.makeText(this, "Hola, $correo", Toast.LENGTH_SHORT).show()
        val intent = Intent(this, ListaActivity::class.java)
        startActivity(intent)
    }

    fun txtRegistroOnClick(view: View) {
        val intent = Intent(this, RegistroActivity::class.java)
        startActivity(intent)
    }
}

Definición
Un Intent también lleva datos
Enviar y
recibir
android:tag
Función: un dato escondido en un componente del XML. No se ve en pantalla; el código lo puede leer.
Ejemplo: android:tag="Tren al Sur;Los Prisioneros": la canción y su artista, separados por punto y coma.
putExtra
Función: agrega un dato al Intent, con un nombre para encontrarlo después.
Ejemplo: intent.putExtra("cancion", "Tren al Sur")
intent (en la pantalla nueva)
Función: el pedido que abrió esta pantalla, con los datos que traía.
Ejemplo: en DetalleActivity, intent es el pedido que mandó la Lista.
getStringExtra
Función: saca un dato del Intent por su nombre.
Ejemplo: intent.getStringExtra("cancion") entrega "Tren al Sur".
