Parte 01
01 · Concepto
El problema de
las filas a mano

Tres canciones se escriben a mano. Doscientas no. Y cuando los datos vengan de Firestore, nadie sabrá de antemano cuántas son.

Definición
El componente de las listas largas
Qué es un
RecyclerView
RecyclerView
Un componente que muestra una lista dibujando una fila por cada dato, siempre con el mismo diseño de fila.
El nombre viene de reciclar: cuando una fila sale de la pantalla al deslizar, se reutiliza para la que entra. Así una lista de mil canciones funciona igual de rápido que una de diez.
Hasta ahoraDesde esta clase
Una fila escrita a mano por cada canciónUn solo diseño de fila, en su propio archivo
Los datos escritos dentro del XMLLos datos en una lista, en el código
Un tag con "canción;artista" en cada filaCada fila sabe qué canción muestra
Las cuatro piezas
Cada una en su archivo, cada una con una sola tarea
Cómo se arma
una lista
1 · El modelo
Función: dice qué datos tiene un elemento de la lista.
Ejemplo: Cancion.kt: título, artista, género y veces escuchada.
2 · El diseño de fila
Función: el XML de una sola fila, sin datos reales.
Ejemplo: item_cancion.xml: carátula, tres textos y el botón +1.
3 · El adaptador
Función: toma cada dato y lo pone en una fila. Es el puente entre los datos y la pantalla.
Ejemplo: CancionAdapter.kt: la canción 3 va en la fila 3.
4 · El RecyclerView
Función: el espacio de la pantalla donde aparecen las filas.
Ejemplo: activity_lista.xml y ListaActivity.kt: aquí van los datos y se conecta el adaptador.

android:layout_height="wrap_content"La fila mide lo justo para su contenido. Es la línea que más se olvida.

android:orientation="vertical"Los tres textos, uno debajo del otro.

package com.example.mimusica

import android.content.Intent
import android.view.LayoutInflater
import android.view.View
import android.view.ViewGroup
import android.widget.Button
import android.widget.TextView
import androidx.recyclerview.widget.RecyclerView

class CancionAdapter(private val canciones: List<Cancion>) :
    RecyclerView.Adapter<CancionAdapter.FilaViewHolder>() {

    class FilaViewHolder(view: View) : RecyclerView.ViewHolder(view) {
        val txtTitulo: TextView = view.findViewById(R.id.txtTituloFila)
        val txtArtista: TextView = view.findViewById(R.id.txtArtistaFila)
        val txtVeces: TextView = view.findViewById(R.id.txtVecesFila)
        val btnMasUno: Button = view.findViewById(R.id.btnMasUno)
    }

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): FilaViewHolder {
        val view = LayoutInflater.from(parent.context).inflate(R.layout.item_cancion, parent, false)
        return FilaViewHolder(view)
    }

    override fun getItemCount(): Int {
        return canciones.size
    }

    override fun onBindViewHolder(holder: FilaViewHolder, position: Int) {
        val cancion = canciones[position]
        holder.txtTitulo.text = cancion.titulo
        holder.txtArtista.text = cancion.artista
        holder.txtVeces.text = "Escuchada ${cancion.veces} veces"

        holder.btnMasUno.setOnClickListener {
            cancion.veces = cancion.veces + 1
            holder.txtVeces.text = "Escuchada ${cancion.veces} veces"
        }

        holder.itemView.setOnClickListener {
            val contexto = holder.itemView.context
            val intent = Intent(contexto, DetalleActivity::class.java)
            intent.putExtra("cancion", cancion.titulo)
            intent.putExtra("artista", cancion.artista)
            intent.putExtra("genero", cancion.genero)
            intent.putExtra("veces", cancion.veces)
            contexto.startActivity(intent)
        }
    }
}

LíneaQué hace
<androidx.recyclerview.widget.RecyclerViewEl nombre completo del componente: no es de los básicos, viene de una librería de Android.
android:id="@+id/rvCanciones"rv por RecyclerView. Con este id se trae al código en el Paso 5.

android:paddingHorizontal="16dp"Margen a los lados de las filas.
tools:listitem="@layout/item_cancion"Solo para la vista previa: repite tu fila para que veas cómo va a quedar. En el teléfono no hace nada.

package com.example.mimusica

import android.content.Intent
import android.os.Bundle
import android.view.View
import androidx.activity.enableEdgeToEdge
import androidx.appcompat.app.AppCompatActivity
import androidx.core.view.ViewCompat
import androidx.core.view.WindowInsetsCompat
import androidx.recyclerview.widget.LinearLayoutManager
import androidx.recyclerview.widget.RecyclerView

class ListaActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContentView(R.layout.activity_lista)
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main)) { v, insets ->
            val systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars())
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom)
            insets
        }

        val canciones = listOf(
            Cancion("Fix You", "Coldplay", "Alternativa", 12),
            Cancion("Tren al Sur", "Los Prisioneros", "Rock", 8),
            Cancion("Gracias a la Vida", "Violeta Parra", "Folclor", 5),
            Cancion("Cuando Pase el Temblor", "Soda Stereo", "Rock", 7),
            Cancion("Ojitos Lindos", "Bad Bunny", "Urbano", 20),
            Cancion("Flowers", "Miley Cyrus", "Pop", 3),
            Cancion("Déjate Caer", "Los Tres", "Rock", 4),
            Cancion("Vivir Mi Vida", "Marc Anthony", "Salsa", 9)
        )

        val rvCanciones = findViewById<RecyclerView>(R.id.rvCanciones)
        rvCanciones.layoutManager = LinearLayoutManager(this)
        rvCanciones.adapter = CancionAdapter(canciones)
    }

    fun btnIAOnClick(view: View) {
        val intent = Intent(this, IAActivity::class.java)
        startActivity(intent)
    }

    fun btnAgregarOnClick(view: View) {
        val intent = Intent(this, BuscarActivity::class.java)
        startActivity(intent)
    }

    fun btnSalirOnClick(view: View) {
        finish()
    }
}

package com.example.mimusica

import android.os.Bundle
import android.view.View
import android.widget.TextView
import android.widget.Toast
import androidx.activity.enableEdgeToEdge
import androidx.appcompat.app.AppCompatActivity
import androidx.core.view.ViewCompat
import androidx.core.view.WindowInsetsCompat

class DetalleActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContentView(R.layout.activity_detalle)
        ViewCompat.setOnApplyWindowInsetsListener(findViewById(R.id.main)) { v, insets ->
            val systemBars = insets.getInsets(WindowInsetsCompat.Type.systemBars())
            v.setPadding(systemBars.left, systemBars.top, systemBars.right, systemBars.bottom)
            insets
        }

        val cancion = intent.getStringExtra("cancion")
        val artista = intent.getStringExtra("artista")
        val genero = intent.getStringExtra("genero")
        val veces = intent.getIntExtra("veces", 0)

        val txtCancion = findViewById<TextView>(R.id.txtCancion)
        val txtArtista = findViewById<TextView>(R.id.txtArtista)
        val txtGenero = findViewById<TextView>(R.id.txtGenero)
        val txtVeces = findViewById<TextView>(R.id.txtVeces)

        txtCancion.text = cancion
        txtArtista.text = artista
        txtGenero.text = genero
        txtVeces.text = "Escuchada $veces veces"
    }

    fun btnEliminarOnClick(view: View) {
        Toast.makeText(this, "Canción eliminada", Toast.LENGTH_SHORT).show()
        finish()
    }
}
LíneaQué hace
val genero = intent.getStringExtra("genero")Recibe el género. El nombre entre comillas tiene que ser igual al del putExtra del adaptador.
val veces = intent.getIntExtra("veces", 0)Para números se usa getIntExtra. El 0 es lo que entrega si el dato no viene.
val txtGenero = findViewById<TextView>(R.id.txtGenero)El TextView del género, que ya estaba en activity_detalle.xml.
txtGenero.text = generoEscribe el género en pantalla.
txtVeces.text = "Escuchada $veces veces"Sin llaves: veces es una variable sola. Las llaves van solo cuando el dato es parte de otro, como ${cancion.veces}.
