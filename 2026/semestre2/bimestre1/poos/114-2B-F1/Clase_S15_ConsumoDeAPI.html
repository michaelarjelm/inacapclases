¿Qué es
una API?
API · Application Programming Interface
Una puerta que un sistema deja abierta para que otros programas le pidan datos, con reglas fijas para pedir y para responder.
mindicador.cl tiene una API que entrega el valor del dólar de hoy.

Toda consulta a una API tiene cuatro pasos. Los armamos uno por uno.

servicios/mindicador.py
import requests


class Mindicador:
    URL = "https://mindicador.cl/api/"

    def __init__(self, timeout: float = 5):
        self.__timeout = timeout

    def valor(self, codigo: str) -> float:
        respuesta = requests.get(self.URL + codigo, timeout=self.__timeout)
        datos = respuesta.json()
        return datos["serie"][0]["valor"]

Hoy, en los tres casos, el programa se cae

Que la API falle no es culpa del programa. Que el programa se caiga, sí.

Definición
Dos herramientas de requests
timeout y
raise_for_status
Timeout
El tiempo máximo de espera. Si se cumple, requests lanza Timeout. Sin timeout, el programa puede quedar congelado.
raise_for_status()
Lanza HTTPError si el código de estado es de error. Si es 200, no hace nada.
●
Con /api/dolarr, a veces llega 200 con un error adentro

Ahí no hay HTTPError: el error aparece al buscar ["serie"]. Hay que atrapar las dos cosas.

Le escriben a agy
"En excepciones.py agrega IndicadorNoDisponibleError, que hereda de Exception. En servicios/mindicador.py, dentro de valor(), llama a raise_for_status() después del get y envuelve todo en un try. Atrapa en este orden Timeout, ConnectionError, HTTPError y, juntos, ValueError, KeyError e IndexError. En cada except lanza IndicadorNoDisponibleError con un mensaje distinto que explique qué falló. No uses except Exception."
servicios/mindicador.py · método valor()
    def valor(self, codigo: str) -> float:
        try:
            respuesta = requests.get(self.URL + codigo, timeout=self.__timeout)
            respuesta.raise_for_status()
            datos = respuesta.json()
            return datos["serie"][0]["valor"]
        except requests.exceptions.Timeout:
            raise IndicadorNoDisponibleError(f"mindicador.cl no respondió en {self.__timeout} segundos")
        except requests.exceptions.ConnectionError:
            raise IndicadorNoDisponibleError("No hay conexión con mindicador.cl")
        except requests.exceptions.HTTPError:
            raise IndicadorNoDisponibleError(f"mindicador.cl respondió con error {respuesta.status_code}")
        except (ValueError, KeyError, IndexError):
            raise IndicadorNoDisponibleError("La respuesta de mindicador.cl no trae el valor esperado")

Si el servidor no acepta la conexión a tiempo, llega ConnectTimeout: calza con los dos except. Python usa el primero. Con ConnectionError arriba, el mensaje diría "no hay conexión" cuando el problema fue la demora.
