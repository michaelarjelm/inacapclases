Panorama
El plan · Dos programas distintos
Vas a instalar
dos cosas

Oracle no es un solo programa, son dos piezas que trabajan juntas. Es importante que entiendas la diferencia, porque a veces los alumnos creen que instalaron todo cuando solo pusieron una mitad.

1. El motor · Oracle XE

Oracle Database XE es la base de datos misma: el "cerebro" que guarda tus tablas y datos. Trabaja por dentro, no tiene una ventana bonita. Una vez instalado, queda corriendo solo en tu PC.

2. El cliente · SQL Developer

SQL Developer es la ventana donde TÚ escribes SQL. Es el programa que abres, escribes SELECT, y le pides al motor que responda. Sin él, no tienes cómo "hablarle" a la base.

💡
La analogía del auto

El motor (Oracle XE) es el motor del auto: hace toda la fuerza, pero no te subes a él directamente. SQL Developer es el volante y el tablero: es por donde tú manejas. Necesitas los dos, y en este orden: primero el motor, después el volante.

Parte A
Parte A · El motor
Instalar
Oracle XE

Primero el motor de la base de datos. Es la parte más larga, pero es "siguiente, siguiente". Sigue cada paso sin saltarte ninguno.

Parte A · Descarga
A · Pasos 1 y 2 · Conseguir el archivo
Descargar
Oracle XE
1
Abre la página de descarga

En tu navegador entra a la página oficial de Oracle XE:

oracle.com/database/technologies/xe-downloads.html

Busca la opción "Oracle Database 21c Express Edition for Windows x64" y haz clic para descargar.

2
Inicia sesión y descarga

Oracle te puede pedir iniciar sesión. Si no tienes cuenta, dale a "Create Account", créala gratis (es solo correo y contraseña) y vuelve.

Se descargará un archivo comprimido .zip de más de 2 GB. Espera a que termine por completo antes de seguir.

⚠
No abras el archivo a medio descargar

Si lo abres antes de que termine, los archivos salen corruptos y la instalación falla. Espera a que la descarga llegue al 100%.

Parte A · Instalación
A · Pasos 3 y 4 · Ejecutar el instalador
Iniciar la
instalación
3
Descomprime el .zip

Haz clic derecho sobre el archivo descargado y elige "Extraer todo...". Espera a que termine. Vas a obtener una carpeta nueva.

4
Ejecuta el instalador como administrador

Entra a la carpeta que se creó y busca el archivo setup.exe.

Haz clic derecho sobre él y elige "Ejecutar como administrador". Si Windows pregunta "¿Permites que esta app haga cambios?", responde Sí.

💡
¿Por qué "como administrador"?

Oracle instala un servicio que corre en segundo plano en Windows. Sin permisos de administrador, la instalación se queda a medias y después no conecta. No te saltes esta parte.

Parte A · Asistente
A · Pasos 5 y 6 · Las pantallas del asistente
Siguiente,
siguiente...
5
Bienvenida y licencia

Se abre una ventana de instalación. En la pantalla de bienvenida presiona Next (Siguiente).

En la pantalla de la licencia, marca "I accept the terms..." (Acepto los términos) y presiona Next.

6
Carpeta de instalación

Te muestra dónde se instalará (algo como C:\app\...). No cambies nada: deja la ruta que viene por defecto y presiona Next.

✓
Regla simple para alumnos

En todo el asistente, salvo el paso de la contraseña (que viene ahora), deja todo como está y presiona Next. No hace falta cambiar ninguna opción.

Parte A · Contraseña
A · Paso 7 · El paso MÁS importante
Define tu
contraseña
7
Escribe una contraseña y ANÓTALA

El asistente te pide crear una contraseña para la base de datos. La escribes dos veces (la segunda es para confirmar).

Esta contraseña es la llave de tu base de datos. La vas a necesitar cada vez que te conectes. Anótala en un lugar seguro ahora mismo.

⚠
Si olvidas esta contraseña, no podrás entrar

No hay un "¿olvidaste tu contraseña?" como en las redes sociales. Recuperarla es muy engorroso. Usa una que recuerdes bien y escríbela. Sugerencia: algo simple pero con una mayúscula y un número, por ejemplo Oracle2026. Evita espacios y empezar con un número.

✓
Dato

Esa misma contraseña sirve para los usuarios internos de Oracle (SYS, SYSTEM y PDBADMIN). Tú vas a usar el usuario SYSTEM con esta contraseña. Recuérdalo para la Parte C.

Parte A · Final
A · Pasos 8 y 9 · Instalar y terminar
Instalar y
finalizar
8
Presiona Install y espera

Llegas a un resumen. Presiona Install. Ahora espera con paciencia: la barra puede tardar varios minutos. No cierres la ventana ni apagues el PC.

9
Lee la pantalla final y presiona Finish

Al terminar aparece una pantalla con un resumen y datos importantes de conexión. No la cierres de golpe: estos datos los usarás en la Parte C.

El motor ya quedó corriendo

Listo: Oracle XE quedó instalado y arranca solo con Windows. No tienes que "abrirlo". Ahora falta el volante: SQL Developer.

"localhost" significa "este mismo computador"

Como el motor está instalado en tu propio PC, le dices a SQL Developer que busque la base en localhost, es decir, "aquí mismo". No necesitas internet para conectarte una vez instalado.

Parte B
Parte B · El cliente
Instalar
SQL Developer

Ahora el programa donde escribirás SQL. Buena noticia: este no tiene instalador, es mucho más rápido que el motor.

Parte B · Descarga
B · Pasos 10 y 11 · Conseguir SQL Developer
Descargar
SQL Developer
10
Abre la página de SQL Developer

En tu navegador entra a:

oracle.com/database/sqldeveloper/

Haz clic en "Download".

11
Elige la versión "with JDK included"

Verás varias opciones. Elige la de Windows 64-bit que diga "with JDK included" (con JDK incluido).

Esto es clave: esa versión trae adentro el Java que SQL Developer necesita. Si bajas la otra, después te pedirá instalar Java aparte y se complica.

⚠
Si no eliges "with JDK included"

SQL Developer no abrirá y te pedirá la ruta de un Java que probablemente no tengas. Para ahorrarte ese dolor de cabeza, baja siempre la versión con JDK incluido.

Parte B · Abrir
B · Pasos 12 y 13 · No se instala, se descomprime
Descomprimir
y abrir
12
Descomprime la carpeta

SQL Developer viene en un .zip. No tiene instalador. Haz clic derecho y "Extraer todo...".

Te recomiendo extraerlo en un lugar fácil de encontrar, por ejemplo dentro de C:\ o en tu carpeta de Documentos.

13
Abre sqldeveloper.exe

Entra a la carpeta que se descomprimió. Adentro busca el archivo sqldeveloper.exe (tiene un ícono rojo) y haz doble clic.

La primera vez tarda más en abrir. Si pregunta si quieres importar configuraciones de una versión anterior, responde No.

✓
Crea un acceso directo

Como no hay instalador, no aparecerá en el menú inicio solo. Haz clic derecho sobre sqldeveloper.exe → "Enviar a" → "Escritorio (crear acceso directo)". Así lo abres rápido la próxima vez.

Parte C · Conexión
C · Pasos 14 y 15 · Crear la conexión
Crear una
conexión
14
Haz clic en el botón verde "+"

Ya con SQL Developer abierto, arriba a la izquierda verás un panel "Connections" (Conexiones) con un botón verde con un "+". Haz clic ahí.

Se abre una ventana llamada "New / Select Database Connection".

15
Rellena los campos con tu ficha

Copia exactamente los valores de tu ficha de la Parte A. Mira la tabla de la lámina siguiente para no equivocarte en ningún campo.

⚠
El error más común está aquí

En la zona de host/puerto hay dos opciones: "SID" y "Service name" (Nombre de servicio). Debes elegir Service name y escribir XEPDB1. Si dejas SID, no conectará.

Parte C · Probar
C · Pasos 16 y 17 · Test y Connect
Probar y
conectar
16
Presiona "Test"

Antes de guardar, presiona el botón "Test" (Probar). Abajo a la izquierda debe aparecer en verde:

17
Presiona "Connect"

Si te salió Success, presiona "Connect" (Conectar). La ventana se cierra y tu conexión XE Local aparece en el panel de la izquierda. ¡Ya estás dentro!

⚠
¿Te salió un error en rojo en vez de Success?

Tranquilo, es normal a la primera. Casi siempre es la contraseña mal escrita o el "Service name" mal puesto. Revisa la lámina de Problemas comunes al final de esta guía: están los errores típicos y cómo solucionarlos.

dual es una tablita de prueba que Oracle trae siempre. Si te respondió, significa que el motor y el cliente están hablando perfecto. Tu Oracle ya está listo para trabajar.

Problemas
comunes

Si te topaste con un error, búscalo aquí. Estos cuatro cubren el 95% de los casos:

Lo que te diceQué hacer
ORA-12541
"TNS: no listener"		 El motor no está corriendo. Abre el menú inicio, escribe "Servicios", busca OracleServiceXE, clic derecho → Iniciar. O simplemente reinicia el PC y vuelve a intentar.
ORA-01017
"invalid username/password"		 Contraseña o usuario mal escritos. El usuario es SYSTEM y la contraseña es exactamente la del paso 7. Cuidado con mayúsculas y el teclado.
ORA-12514
"listener does not know of service"		 El "Service name" está mal. Asegúrate de haber elegido la opción Service name (no SID) y escrito XEPDB1.
