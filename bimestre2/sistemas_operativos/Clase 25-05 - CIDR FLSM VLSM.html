CIDR — Enrutamiento Inter-Dominio sin Clases

CIDR — Definición

¿Qué es CIDR?

El CIDR (Classless Inter-Domain Routing) es un método de direccionamiento IP introducido para reemplazar el sistema basado en clases (A, B, C).

A diferencia del modelo clásico, donde el tamaño de red estaba determinado por el primer octeto, CIDR permite usar cualquier cantidad de bits para la parte de red, según lo requiera el diseño.

Clave: la máscara ya no está fija por clase — tú decides cuántos bits son para red.

CIDR — Definición

Slash Notation y flexibilidad

CIDR usa la notación slash (p.ej. /24, /26, /30), donde el número indica cuántos bits identifican la red.

  • Permite crear subredes de tamaños personalizados.
  • Mejora el uso del espacio de IPs y reduce el desperdicio.
  • Facilita el enrutamiento jerárquico y eficiente en Internet.
  • Hoy es el estándar en redes modernas y enrutadores.

FLSM — Máscara de Subred de Longitud Fija

FLSM — Definición

¿Qué es FLSM?

FLSM es una técnica de subneteo donde todas las subredes generadas tienen el mismo tamaño: usan la misma máscara y permiten la misma cantidad de hosts válidos.

Se divide una red original en partes iguales, sin considerar si cada subred realmente necesita ese espacio o no.

Ejemplo: 4 departamentos con ~25 dispositivos cada uno. Todos reciben una subred /26 (62 hosts válidos).

FLSM — Características

Ventajas de FLSM

  • Simplicidad en el diseño: todas las subredes tienen el mismo tamaño, lo que facilita la planificación.
  • Fácil administración: más fácil de documentar y supervisar, ideal en entornos educativos.
  • Menor probabilidad de errores: bloques fijos y repetitivos reducen el riesgo de solapar rangos.
  • Uniformidad: ideal cuando todos los segmentos tienen necesidades similares de hosts.
Diseño
Todos los bloques son iguales — sin cálculos por área.

Errores
Difícil equivocarse con bloques fijos.

FLSM — Características

Desventajas de FLSM

  • Poca eficiencia en el uso de IPs: asignas el mismo número de IPs a todos, aunque algunos no las necesiten.
  • No se adapta a requerimientos variables: si un depto. necesita 50 IPs y otro solo 5, ambos reciben el mismo bloque.
  • Escalabilidad limitada: en redes grandes, mantener bloques fijos lleva al agotamiento de IPs más rápido.
Ejemplo: una red con 10 hosts usa Clase C (/24) → se desperdician 244 direcciones.

VLSM — Máscara de Subred de Longitud Variable

VLSM — Definición

¿Qué es VLSM?

VLSM es una técnica de subneteo que permite crear subredes de diferente tamaño, usando máscaras variables según la cantidad real de dispositivos que necesita cada red.

A diferencia de FLSM, donde todas las subredes son iguales, VLSM se adapta a las necesidades específicas de cada área, optimizando el uso de IPs y evitando el desperdicio.

Principio: asignar a cada subred exactamente lo que necesita — ni más, ni menos.

Seguridad necesita solo 2 → subred mínima /30 con 2 hosts válidos. Se asigna 192.168.1.112/30 (continúa donde terminó Gerencia en .111).
