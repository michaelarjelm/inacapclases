CIDR — Enrutamiento Inter-Dominio sin Clases

CIDR — Definición

¿Qué es CIDR?

El CIDR (Classless Inter-Domain Routing) es un método de direccionamiento IP introducido para reemplazar el sistema basado en clases (A, B, C).

A diferencia del modelo clásico, donde el tamaño de red estaba determinado por el primer octeto, CIDR permite usar cualquier cantidad de bits para la parte de red, según lo requiera el diseño.

Clave: la máscara ya no está fija por clase — tú decides cuántos bits son para red.

CIDR — Definición

Slash Notation y flexibilidad

CIDR usa la notación slash (p.ej. /24, /26, /30), donde el número indica cuántos bits identifican la red.

  • Permite crear subredes de tamaños personalizados.
  • Mejora el uso del espacio de IPs y reduce el desperdicio.
  • Facilita el enrutamiento jerárquico y eficiente en Internet.
  • Hoy es el estándar en redes modernas y enrutadores.

Rango de 192.168.10.0/26

Dirección de red, primera/última IP válida y broadcast de 192.168.10.0/26.

Paso 1Bits de host: 32 − 26 = 6
Paso 2Bloque: 26 = 64 direcciones totales
Paso 3Dirección de red: 192.168.10.0  (todos bits host = 0)
Paso 4Primer host válido: 192.168.10.1
Paso 5Último host válido: .0 + 64 − 2 = 192.168.10.62
Paso 6Broadcast: .0 + 64 − 1 = 192.168.10.63  (todos bits host = 1)
RespuestaRed .0 · Hosts .1–.62 · BC .63
