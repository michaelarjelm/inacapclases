¿Qué es una dirección IP?

Una dirección IP es como el "número de identificación" de cada dispositivo en una red.

Así como tú tienes un RUT o tu celular un número único, cada computador, teléfono o impresora en una red necesita una dirección IP para comunicarse.

Modelo por Clases

El modelo de direccionamiento por clases es el método usado para asignar direcciones IPv4, en el que la estructura de la IP estaba determinada por su primer octeto.

Según ese valor, una IP pertenecía a una clase y cada clase tenía una máscara de subred fija y predefinida.

Clases disponibles: A, B, C, D, E.
El primer octeto lo define todo
192.168.1.10
192 ∈ [192–223]
CLASE C
Determinación automática de máscara
18

Modelo por Clases

Característica principal: no se puede elegir cuántos bits son para red o host — viene definido por la clase.

Las tres clases principales para redes:

  • Clase A → /8  255.0.0.0
  • Clase B → /16 255.255.0.0
  • Clase C → /24 255.255.255.0
Clase A — Prefijo /8
RED.HOST.HOST.HOST
Clase B — Prefijo /16
RED.RED.HOST.HOST
Clase C — Prefijo /24
RED.RED.RED.HOST
19

Modelo por Clases

Ejemplo: la IP 192.168.0.10 comienza con 192 → Clase C → máscara fija 255.255.255.0 (/24).

¿Desde Binario a IP?

Las direcciones IPv4 internamente se representan como una secuencia de 32 bits (32 unos y ceros).

Para que los humanos podamos leerlas, se dividen en 4 bloques de 8 bits, y cada bloque se convierte a un número decimal entre 0 y 255.

¿Desde Binario a IP?

Cada bit de un octeto corresponde a los siguientes valores posicionales:

128 · 64 · 32 · 16 · 8 · 4 · 2 · 1

Equivalentes en potencias: 27, 26, 25, 24, 23, 22, 21, 20.

¿Desde Binario a IP?

Para transformar 11000000.10101000.00000001.00001010 hay que "cuadrar" los valores según la tabla posicional.

Primer octeto (11000000):

128 + 64 + 0 + 0 + 0 + 0 + 0 + 0 = 192
