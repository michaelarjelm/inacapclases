Concepto
01 — ¿Qué es AWS Academy?
La plataforma que
usaremos este semestre

AWS Academy es un programa educativo de Amazon Web Services que entrega acceso gratuito a la infraestructura en la nube de AWS para uso académico. Cada alumno tiene una cuenta personal con créditos para usar durante el semestre.

En términos simples: es como tener un datacenter en la nube disponible para practicar, sin pagar nada. Dentro de AWS Academy podrás crear servidores reales, configurarlos y destruirlos sin consecuencias económicas.

  • Learner Lab: el laboratorio donde crearás y gestionarás tus servidores.
  • Consola de AWS: la interfaz web desde donde controlas todos tus recursos.
  • Créditos: cada laboratorio tiene un tiempo limitado de sesión. Al cerrar, los recursos se detienen pero no se eliminan.
⚠
El laboratorio tiene tiempo límite por sesión

Cada vez que inicies el laboratorio tienes un tiempo activo. Al expirar, las instancias se detienen automáticamente. La próxima sesión debes volver a iniciarlo y las instancias se reanudan.

04 — Consola · Orientación inicial
Recorrido por
la consola de AWS

Al abrir la consola de AWS por primera vez puede parecer abrumadora. Hay cientos de servicios disponibles. Para esta unidad usaremos principalmente EC2, que es el servicio que nos permite crear y gestionar servidores virtuales.

✓
Forma más rápida de llegar a EC2

Usa la barra de búsqueda superior y escribe "EC2". Aparecerá como primer resultado. Haz clic para entrar.

Navegación
04 — Consola · Panel EC2
El panel de EC2

EC2 (Elastic Compute Cloud) es el servicio de AWS para crear servidores virtuales. Desde su panel podrás ver, iniciar, detener y eliminar tus instancias.

💡
Verifica la región

En la esquina superior derecha aparece la región de AWS donde estás trabajando (ej: us-east-1). Todos los recursos que crees quedan en esa región. No la cambies durante el semestre o no verás tus instancias.

05 — Instancia
Bloque 05
Lanzar instancia
Windows Server

Una instancia es un servidor virtual en la nube. Vamos a crear uno con Windows Server, el sistema operativo que configuraremos durante esta unidad.

Pasos
05 — Instancia · Launch Instance
Crear la instancia:
parte 1
1
En EC2, haz clic en Launch Instance
Botón naranja en la esquina superior derecha del panel de instancias.
2
Asigna un nombre a la instancia
Ejemplo: WinServer-Manual. Usar nombres descriptivos es una buena práctica.
3
Selecciona la AMI: Windows Server 2019 Base
En la sección "Application and OS Images". Busca "Windows Server 2019" y selecciona la imagen base gratuita (Free tier eligible).
4
Tipo de instancia: t2.micro
Es la opción gratuita (Free tier). Suficiente para las prácticas del curso.
Pasos
05 — Instancia · Launch Instance
Crear la instancia:
parte 2
5
Key pair: Proceed without a key pair
Para Windows Server obtendremos la contraseña de otra forma. Selecciona esta opción para simplificar.
6
Network settings: habilitar RDP (puerto 3389)
Marca la casilla "Allow RDP traffic from" y selecciona "Anywhere". Esto permite conectarse al servidor desde cualquier IP.
7
Haz clic en Launch Instance
AWS comenzará a crear tu servidor. El proceso tarda entre 3 y 5 minutos. El estado inicial será "pending" y luego cambiará a "running".
✓
Verifica el estado en el panel de instancias

Ve a EC2 → Instances. Tu instancia aparecerá en la lista. Espera hasta que el estado diga Running y los checks de estado sean 2/2 antes de intentar conectarte.

06 — RDP
Bloque 06
Conectarse
via RDP

RDP (Remote Desktop Protocol) es la forma estándar de conectarse a un servidor Windows de forma remota. Es como sentarse frente al servidor desde tu computador.

Pasos
06 — RDP · Obtener credenciales
Obtener la contraseña
del servidor
1
Selecciona tu instancia en EC2 → clic derecho → Connect
O usa el botón "Connect" en la barra superior cuando la instancia está seleccionada.
2
Pestaña RDP client → Get password
AWS generó una contraseña automática para el administrador del servidor.
3
Copia la IP pública, el usuario y la contraseña
Usuario por defecto: Administrator. Guarda estos datos, los necesitarás para conectarte.
4
Descarga el archivo .rdp
AWS genera un archivo de conexión listo para usar. Descárgalo y ábrelo directamente.
Pasos
06 — RDP · Conexión desde Windows
Abrir la conexión
RDP
1
Abre el archivo .rdp descargado
Windows abrirá automáticamente la aplicación de "Conexión a Escritorio Remoto".
2
Acepta la advertencia de certificado
Es normal para entornos de laboratorio. Haz clic en Sí o Conectar de todas formas.
3
Ingresa las credenciales
Usuario: Administrator | Contraseña: la que copiaste desde AWS. Haz clic en Aceptar.
4
¡Estás dentro del servidor!
Verás el escritorio de Windows Server. La primera vez puede tardar unos segundos en cargar completamente.
