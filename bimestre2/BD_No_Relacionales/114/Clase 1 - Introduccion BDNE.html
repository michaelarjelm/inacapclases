¿Qué es una base de datos?

Una Base de Datos (BD) es un conjunto organizado de datos relacionados que se almacenan de manera estructurada para facilitar su acceso, administración y actualización.

Su propósito principal es permitir que los datos sean fácilmente recuperables y utilizables de forma eficiente.

Bases de Datos NO Relacionales

Las bases de datos No Relacionales (NoSQL) son sistemas de almacenamiento de datos diseñados para gestionar grandes volúmenes de información que no se ajustan a un esquema estructurado rígido (como el de las bases de datos relacionales).

A diferencia de las bases de datos relacionales, NoSQL no utiliza tablas con filas y columnas, sino que emplea modelos de datos más flexibles como documentos, pares clave-valor, columnas anchas o grafos.

¿Qué es Redis?

Redis es una base de datos en memoria de tipo clave-valor (con soporte de estructuras como strings, listas, sets y hashes) diseñada para ofrecer lecturas y escrituras extremadamente rápidas y de baja latencia.

Por eso se usa ampliamente como caché, almacenamiento de sesiones, contadores y colas simples. También puede persistir datos en disco y replicarse para alta disponibilidad, aunque su principal fortaleza es el rendimiento al trabajar con datos que se consultan con frecuencia.

¿Qué es Apache Cassandra?

Apache Cassandra es una base de datos distribuida NoSQL de tipo wide-column diseñada para manejar grandes volúmenes de datos con alta disponibilidad y escalabilidad horizontal, replicando información entre múltiples nodos y centros de datos para evitar puntos únicos de falla.

Se usa cuando se necesita baja latencia y tolerancia a fallos. Su modelo prioriza consultas por claves de partición, lo que implica diseñar las tablas según los patrones de lectura más frecuentes y, a menudo, duplicar datos en varias tablas para responder consultas específicas.

Clave del modelo: en Cassandra se crean múltiples tablas para la misma información, cada una optimizada para un patrón de consulta distinto. No hay JOINs — el diseño reemplaza esa necesidad.

¿Qué es Neo4j?

Neo4j es una base de datos de grafos que almacena la información como nodos (por ejemplo, personas o películas) y relaciones (por ejemplo, "ACTUÓ_EN", "DIRIGIÓ") con propiedades.

Optimizada para recorrer conexiones de forma rápida y responder consultas sobre vínculos, rutas y patrones de relación. Se consulta principalmente con Cypher, un lenguaje orientado a grafos.

Se usa en casos como recomendaciones, detección de fraude, análisis de redes, dependencias entre sistemas y cualquier problema donde las relaciones sean tan importantes como los datos.

¿Un poco de Neo4j?

Vamos al siguiente link https://neo4j.com/sandbox/, hacemos login, seleccionamos la BD de películas y ejecutamos el siguiente código:

Cypher: el lenguaje de consultas de Neo4j. Los nodos se representan con (variable:Etiqueta) y las relaciones con -[:TIPO]->
neo4j — Cypher
// 1) Ver 25 películas con su año MATCH (m:Movie) RETURN m.title AS pelicula, m.released AS anio ORDER BY anio DESC, pelicula LIMIT 25; // 2) Top 10 actores con más películas MATCH (p:Person)-[:ACTED_IN]->(m:Movie) RETURN p.name AS actor, count(m) AS peliculas ORDER BY peliculas DESC, actor LIMIT 10; // 3) Filmografía de un actor específico MATCH (p:Person {name: "Tom Hanks"})-[:ACTED_IN]->(m:Movie) RETURN m.title AS pelicula, m.released AS anio ORDER BY anio, pelicula; // 4) Actores de una película específica MATCH (p:Person)-[r:ACTED_IN]->(m:Movie {title: "The Matrix"}) RETURN p.name AS actor, r.roles AS roles ORDER BY actor;

¿Características principales?
Modelo Documental

Los datos se almacenan como documentos JSON (internamente BSON, una versión binaria de JSON).

BSON extiende JSON con tipos adicionales: Date, ObjectId, BinData, entre otros. Esto permite mayor eficiencia en almacenamiento y consulta.

¿Qué es MongoDB?

MongoDB es una base de datos NoSQL orientada a documentos. A diferencia de las bases relacionales, no impone un esquema fijo: cada documento dentro de una colección puede tener una estructura diferente, lo que la hace ideal para datos cambiantes o semiestructurados.

Está diseñada para escalar horizontalmente mediante sharding, distribuyendo los datos entre múltiples servidores para manejar grandes volúmenes con alta disponibilidad.

24

¿Qué es MongoDB?
Drivers y Compatibilidad

MongoDB ofrece drivers oficiales para los principales lenguajes de programación como Python, Java y Node.js, lo que permite conectarse y operar con la base de datos desde cualquier aplicación.
