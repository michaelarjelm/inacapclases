Bloque 01
Listas — Agregar y Buscar
append
count · index

Tres de los métodos más usados al trabajar con listas. Permiten agregar elementos al final, contar cuántas veces aparece un valor y encontrar en qué posición está un elemento.

.append(x) .count(x) .index(x)
Referencia rápida
Sintaxis de los 9 métodos de lista
Cheatsheet
de métodos
.append(x)
Agrega x al final de la lista
.count(x)
Retorna cuántas veces aparece x
.index(x)
Retorna el índice de la primera ocurrencia de x
.pop()
Elimina y retorna el último elemento. .pop(i) elimina el índice i
.remove(x)
Elimina la primera ocurrencia de x por valor
.reverse()
Invierte el orden de la lista en su lugar
.sort()
Ordena la lista ascendente. .sort(reverse=True) descendente
.copy()
Retorna una copia independiente de la lista
.clear()
Elimina todos los elementos dejando la lista vacía
💡
Métodos que modifican en su lugar vs. los que retornan valor

sort(), reverse(), append(), remove(), clear() modifican la lista original y retornan None. pop(), count(), index() y copy() retornan un valor útil.

03 — copy · Crear una copia independiente

⚠
¿Por qué usar .copy() y no solo lista2 = lista1?

Si haces b = a ambas variables apuntan a la misma lista. Modificar b también modifica a. Con b = a.copy() obtienes una lista independiente.

Bloque 05
Slicing de Listas
lista
[inicio:fin]

El slicing permite extraer sublistas usando índices. No modifica la lista original, retorna una nueva lista. Acepta índices positivos, negativos, y un paso opcional.

lista[1:3] lista[-2:] lista[1:-1] lista[::2] lista[::-1]
Concepto
05 — Slicing · Cómo funciona
Anatomía del
slicing

lista[inicio:fin:paso] — retorna los elementos desde el índice inicio hasta fin - 1. Si se omite inicio usa el principio; si se omite fin usa el final.

Lista de ejemplo: miLista = [1, 2, 3, 4]

1
índice 0
índice -4
2
índice 1
índice -3
3
índice 2
índice -2
4
índice 3
índice -1
Reglas clave
  • fin no se incluye: [1:3] da índices 1 y 2
  • Índice negativo cuenta desde el final
  • Si inicio >= fin, retorna lista vacía
  • Índice fuera de rango no genera error
  • [::paso] salta elementos, [::-1] invierte
Ejemplos rápidos
miLista = [1, 2, 3, 4]

miLista[1:3]   # [2, 3]
miLista[:2]    # [1, 2]
miLista[2:]    # [3, 4]
miLista[-2:]   # [3, 4]
miLista[1:-1]  # [2, 3]
miLista[::-1]  # [4, 3, 2, 1]

Sistema de prioridades — invertir orden de atención
La lista de tareas está ordenada de menor a mayor prioridad. El sistema de despacho debe procesarlas de mayor a menor (crítica primero), sin modificar la lista original.
# Prioridades de menor a mayor
prioridades = ["Baja", "Media", "Alta", "Critica"]

# [::-1] invierte sin modificar la original
orden_atencion = prioridades[::-1]
print(f"Despacho: {orden_atencion}")
# Despacho: ['Critica', 'Alta', 'Media', 'Baja']

# Funciona igual con strings
codigo = "odanretla otxet"
print(codigo[::-1])
# texto alterado
Resumen slicing avanzado
[1:-1] excluye primer y último elemento
[::2] toma un elemento de cada 2
[::-1] invierte completamente la lista
[2:8:2] desde 2 hasta 7, de 2 en 2
✓
Slicing no modifica el original

Siempre retorna una nueva lista. La original queda intacta, a diferencia de sort() y reverse().

.append(x)
Agrega x al final. No retorna valor útil.
.count(x)
Retorna cuántas veces aparece x en la lista.
.index(x)
Retorna el índice de la primera ocurrencia de x.
.pop() / .pop(i)
Elimina y retorna el último elemento o el índice i.
.remove(x)
Elimina la primera ocurrencia de x por valor.
.reverse()
Invierte la lista en su lugar. No retorna valor.
.sort()
Ordena ascendente. .sort(reverse=True) para descendente.
.copy()
Retorna copia independiente. Evita efectos no deseados.
.clear()
Vacía la lista. Equivale a del lista[:] pero más legible.
dict.popitem()
